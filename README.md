# Photo Review Cinema · 今晚回顾

两个人一起回顾旅行，顺手留下值得保存的照片与视频。

采用 Windows 电脑伴侣 + iPad Safari 的本地工作流。电脑负责素材准备、进度保存和整理，iPad 负责沉浸观看与共同选择。Eagle 和普通文件夹使用同一套观看流程。

## 两种方案

- [Eagle 方案](EAGLE.md)：从 Eagle 相册准备素材，筛选后核对并写回星级，去除项移入 Eagle 回收站。
- [文件夹方案](FOLDER.md)：拖入旅行文件夹，筛选后将原片复制到分类目录，默认保留原文件。
- [共用观看流程与判定规则](WORKFLOW.md)
- [实施阶段与验收](ROADMAP.md)

## 当前状态

本仓库当前交付工作流设计文档，不是可直接运行的桌面应用。

Eagle 原型已实现照片双人筛选、相似组 PK、双指缩放、长按快切、视频穿插、待去除阵列、共同精选、进度保存及判定 JSON 校验与写回。统一桌面入口、通用文件夹导入和原片分类整理仍待开发。实体 iPad 的交互验收仍需补齐。

仓库只保存通用方案，不包含私人照片、视频、图库标识、个人判定 JSON、历史进度或执行记录。历史 Eagle 进度留在本地，与代码和文档版本分开管理。

## 产品原则

- 默认继续上次旅行，尽量没有设置门槛。
- 星级用于 Eagle；普通用户看到自然语言分类。
- 原事件日志可重放，执行记录可追溯。
- 已准备、已看完、已落实分别记录，不用评分推断是否筛选过。
- 默认局域网，不依赖账号、云端上传或内网穿透。
